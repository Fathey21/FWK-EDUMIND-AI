# FWK EDUMIND AI 🚀

تطبيق ويب تقدمي (PWA) متكامل وشامل مدعوم بالذكاء الاصطناعي (Gemini 3.5) لخدمة الطلاب وأعضاء هيئة التدريس. تم تصميم النظام بالكامل بأحدث التقنيات ليوفر تجربة مستخدم سريعة، حديثة، وقابلة للتثبيت على الهواتف وأجهزة الكمبيوتر (PWA).

## ✨ الخدمات والمميزات الذكية (Features)
* **دعم الـ PWA بالكامل:** التطبيق يدعم التثبيت (Installable) كـ تطبيق مستقل على الهاتف أو الكمبيوتر مع دعم العمل بدون إنترنت أو في ظروف الشبكة الضعيفة.
* **تلخيص المحاضرات بالذكاء الاصطناعي (Gemini 3.5):** تلخيص أكاديمي ذكي واحترافي للمحاضرات ومحتوى المناهج.
* **تجهيز الأسئلة والتدريبات:** إنشاء بنوك أسئلة وتدريبات تفاعلية وتصديرها مباشرة بصيغة Microsoft Word.
* **إدارة اللجان والامتحانات:** نظام ذكي لتوزيع وتتبع تفاصيل الجداول، اللجان، وأعمال الامتحانات الأكاديمية.
* **الخرائط التفاعلية للمباني:** تتبع مباني الكلية والمرافق والوصول إليها عبر خرائط تفاعلية لتسهيل الحركة داخل الحرم الجامعي.

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Frontend:** React 18, TypeScript, Tailwind CSS, Vite
* **Backend:** Express.js (Node.js)
* **AI Integration:** Gemini 3.5 API
* **Icons & UI:** Lucide React, Modern UI components
